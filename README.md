# iDance portrait kiosk

純 HTML / CSS / JavaScript，無需安裝套件或 build。

## 開啟

直接用瀏覽器開啟 `index.html`，或在此資料夾執行：

```sh
python3 -m http.server 8080
```

瀏覽 `http://localhost:8080`。正式 kiosk 請使用直向 1080 × 1920 螢幕並開啟瀏覽器全螢幕模式。
其他尺寸會保持 9:16 比例完整縮放，畫面外留黑邊。

## 檔案

- `index.html`：主頁結構、開場影片。
- `styles.css`：配色、1080 × 1920 排版、產品卡片。
- `app.js`：產品資料、分類、影片及點擊操作。
- `assets/demo-poster.jpg`：由提供的鍵盤截圖產生的預覽圖。

## 操作

- 開場自動靜音循環播放 `vo/web-vo.mp4`，點任何位置進入主頁。
- 主頁閒置 3 分鐘會返回開場，從頭播放 `vo/web-vo.mp4`；觸碰、滑鼠移動、滾動或按鍵會重新計時。
- 影片中央播放按鈕播放示範影片；播放器提供音量及全螢幕控制。
- 分類按鈕篩選產品；沒有資料的分類顯示提示。
- 產品卡片可點擊選取，以青色外框標示，並在上方播放器切換及播放對應影片；不設彈窗或箭咀。

## 替換正式內容

`app.js` 頂部的 `products` 集中管理名稱、價錢、圖片、影片及分類。
目前是版面展示資料：價格參照設計圖；部分產品圖片、名稱、分類及影片配對需要品牌方確認。
提供的素材與參考圖不同，因此使用本地可用圖片，並非逐像素還原。
未提供獨立品牌 logo，目前頁首使用文字／符號佔位，正式使用時請換成品牌 SVG 或透明 PNG。
